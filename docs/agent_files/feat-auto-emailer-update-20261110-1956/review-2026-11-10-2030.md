## Notes

1. **"Spreadsheet not in list" workaround unreliable.** `DriveApp.searchFiles(...)` has no ordering, so **Make a copy** does not guarantee the sheet lands in the first 50; count also includes sheets shared with the user, so "remove old sheets" only helps if total drops to ≤50. Consider wording it as "may help" or removing the copy tip.
2. **Start from Row option misses earlier failures.** "Note the last person who got the email, start from next" skips any earlier rows that failed / had no email; troubleshooting row "No email address … fill it in, then continue" then won't resend them under that option. Only the `Already Sent` option covers it. No duplicate-send risk.
3. **Privacy "code is public here, so anyone can check it".** The deployed web app version is not necessarily the repo version, and users cannot verify the deployment. Slight overclaim; low harm.
