# Privacy

Your personal details stay anonymous. We collect your organization name.

## What is collected

- tool and version
- event type
- test-or-real flag
- organization name as typed (lowercased)
- random code
- counts (items, ok, failed)
- failing step (plus a reason category from the Google script)
- automation chosen (plugin) / whether a send stopped early (script)
- UTC time
- a run code
- which AI or app sent it (Claude, Google Apps Script, GPT, Gemini, Grok, Perplexity, other: a category only)

## What is never collected

- IP address
- country
- raw user-agent text
- names
- emails
- recipients
- partner lists
- events
- file, draft or sheet names or contents
